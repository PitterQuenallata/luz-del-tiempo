# Imágenes de la demo

Aquí van las imágenes generadas con Gemini, con el nombre exacto que dice
`docs/PROMPTS-IMAGENES-GEMINI.md` (por ejemplo `hero-radio.jpg`).
Si una falta, la web muestra su diseño sin foto.

Solo para la demo al cliente: en producción se reemplazan por fotos reales del ministerio.

## Importante

- Esta carpeta está en `.gitignore` y se borra de `dist/` al compilar (ver `vite.config.ts`).
- Algunas fotos actuales son **recortes de material de SUMtv**, solo como referencia visual para
  la demo en desarrollo. No se publican ni se usan en producción.
